# EV案件管理表 → 銀行提出用 A3 Excel

毎月（または銀行から依頼があったとき）、EV保守成約案件の一覧を
銀行に提出できる体裁の Excel にして渡すための手順です。

## 前提・鉄則

- **元のスプレッドシートは絶対に編集しない。** 読み取り（ダウンロード）だけを行う。
- 出力は必ず新しい Excel ファイルとして作る。上書きもしない。

## 対象

| | |
|---|---|
| スプレッドシート | 【EVPT】エレベーター特約店管理表 |
| ファイルID | `13rlp9ntARMDjD1f8QZUmMhSJ3uWmCAu0eM1vXrZpXXg` |
| シート | `【成約済】EV案件 管理表`（gid=21568204） |
| 保存先 | `G:\共有ドライブ\★Kevin\☆重要\f\EV関連`（無ければ自動で作成） |
| ファイル名 | `【EVPT】エレベーター特約店管理表YYMMDD.xlsx`（YYMMDD＝作成日） |

## 手順

1. スプレッドシートを **.xlsx でダウンロード**する。
   - 手動：スプレッドシートを開き `ファイル > ダウンロード > Microsoft Excel (.xlsx)`
   - Claude から：Google Drive コネクタの `download_file_content` に
     `exportMimeType: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
     を指定してダウンロードし、base64 をデコードして保存する。
2. 変換スクリプトを実行する。PowerShell のラッパーは**引数なし**でも動く
   （ダウンロードフォルダの最新 【EVPT】〜.xlsx を自動で拾い、保存先を開く）。

   ```powershell
   .\scripts\Make-EvBankReport.ps1
   ```

   ```bash
   # Python を直接叩く場合
   python scripts/make_ev_bank_report.py <ダウンロードした.xlsx>
   ```

   - 保存先を変えるとき：`-o "D:\別のフォルダ"`
   - 作成日を指定するとき：`--date 260511`（YYMMDD の 6 桁。既定は実行日）
   - ページ数を変えるとき：`--pages 4`（少ないほど文字は小さくなる）
3. できた Excel を開き、`Ctrl+P` → 用紙 **A3・横**（設定済み）でそのまま印刷する。

## スクリプトが行っていること

- **印刷する行を絞る**
  - 出力18列がすべて空の行に当たったら、**その行以降は対象外**（現データでは 267 行目）
  - `開始月` が `凛` の行は除外（`EXCLUDE_START_MONTH`）
  - 印刷範囲は明細の最終行まで。余計な空白ページは出ない
- **不要な列を削除**（銀行提出では使わない社内管理列）
  `PT①` / 2つ目の `担当` / `既存契約` / `仕様` / `ベンダー` / `既存料金` / `結果番号` /
  Z列以降の集計ダッシュボード / 1〜3行目の社内メモ
- **残す列**（18列）
  `成約Code` `担当` `顧客名` `物件名` `開始月` `弊社入金月` `提案内容` `基数`
  `契約形態` `点検頻度` `OP` `仕切` `見積料金` `❶EVPT売上` `❷PTI` `❸EVPT NP` `結果` `備考`
- **ページ数に合わせて自動で拡大**
  `--pages`（既定 5）に収まる範囲で列幅と文字サイズを自動決定。
  現データ 262 件なら 5 ページ・紙の上で約 9pt
- **A3 横・横1ページ幅**の印刷設定。見出し行は全ページで繰り返す
- **見やすさの工夫**：担当ごとの色分け／列グループごとの見出し色と太い縦罫線／
  開始年が変わる行の区切り線／1行おきの薄い縞／`結果` のチップ風色分け／
  失注・解約の行は文字を薄く／`❸EVPT NP` を太字／`¥0` を薄いグレー
- 数式は計算結果の値に確定させ、`#VALUE!` などのエラー表示は空欄にする

## 対象行の決め方

`成約Code` は未採番の行があるため使わない。**出力18列のどれかに値が入っている行**を
1件として数え、**すべて空の行に当たった時点で打ち切る**。

## 列が増減したとき

スクリプトは列位置ではなく **見出し名** で列を探すため、元シートで列が
移動・追加されても追従する。見出し名そのものが変わった場合だけ
`scripts/make_ev_bank_report.py` の `COLUMNS` を直す。

## 見た目を変えたいとき

`scripts/make_ev_bank_report.py` 冒頭の設定で調整する。

| 変えたいこと | 定数 |
|---|---|
| 既定のページ数 | `TARGET_PAGES` |
| フォント | `FONT_NAME` |
| 文字サイズの上下限 | `FONT_MIN` / `FONT_MAX` |
| 列幅の探索範囲 | `WIDTH_FACTOR_MIN` / `WIDTH_FACTOR_MAX` |
| 折り返しの判定 | `WRAP_THRESHOLD` / `MAX_LINES` |
| 担当ごとの色 | `OWNER_FILLS` / `OWNER_PALETTE` |
| 列グループと見出し色 | `COLUMN_GROUPS` |
| `結果` の色分け | `RESULT_STYLES` |
| A3 の向き | `ORIENTATION` |
| 列の取捨と列幅の配分 | `COLUMNS`（幅は「半角何文字ぶん」で指定） |
| 除外する `開始月` の値 | `EXCLUDE_START_MONTH` |
| 保存先 | `DEFAULT_OUT_DIR` |
| ファイル名の頭 | `FILE_STEM` |

詳細な手順書は [`docs/ev-bank-report.md`](../../../docs/ev-bank-report.md)。
