# 逓減単価（パフォーマンスチャージ）のカウンター明細

## この明細の見分け方

次のどれかがあれば逓減単価。一律単価として読むと金額が合わない。

- 「1－ 1000 ／月」「1001－ 2000 ／月」のように、枚数の帯ごとに単価が並んでいる
- 「控除 2%の控除カウント」「控除 3%の控除カウント」という行がある
- 「パフォーマンスチャージ」という語がある
- フルカラーが「コピー」と「プリント」に分かれ、**単価が違う**（16.8円と13.9円など）

## 金額の作り方

上から順に。**枚数を出す → 控除を引く → 段ごとに単価をかける**。

1. **カウント = 今回指針 − 前回指針**
   指針（メーター値）の差が実際の出力枚数。明細に「ご使用カウント」列があればそれと一致するはず。

2. **控除カウント = カウント × 控除率（切り上げ）**
   ミスプリント等を無償にする仕組み。**切り上げ**である点に注意（382×3% = 11.46 → 12）。

3. **請求カウント = カウント − 控除カウント**

4. **段ごとに単価をかける**
   段は「1ヶ月あたりの枚数」で区切る。上の段から順に埋め、あふれた分を次の段へ送る。
   請求カウント1,361枚なら「1-1000に1,000枚」「1001-2000に361枚」。

5. **段ごとの金額は小数を切り捨て**、最後に合計する。
   361 × 2.6円 = 938.6 → 938円。段の金額を出してから足すので、先に合計してから丸めると1円ずれる。

区分（モノクロ／フルカラーコピー／フルカラープリント）ごとにこれを行い、最後に全区分を合計する。

## 必ず検算する

出した合計が明細の「ご請求金額（税抜）」と**1円単位で一致**するか確かめる。
合わないときは、読み取りではなく解釈が間違っている。よくある原因は次のとおり。

- 控除を引き忘れている／四捨五入してしまった（正しくは切り上げ）
- フルカラーのコピーとプリントを一緒にしてしまった（単価が違う）
- 段の割り当てを間違えた（上の段から順に埋める）
- 段ごとに切り捨てず、合計してから丸めた

## 実例（検算済み）

リコー MPC3003SP／2026年5月分／請求 9,937円（税抜）。この読み方で1円まで一致する。

| 区分 | 指針差 | 控除 | 請求カウント | 段 | 単価 | 金額 |
| --- | ---: | ---: | ---: | --- | ---: | ---: |
| モノカラー総出力 | 1,389 | 2% → 28 | 1,361 | 1–1000 | 3.0円 | 3,000 |
|  |  |  |  | 1001–2000 | 2.6円 | 938 |
| フルカラーコピー | 53 | 3% → 2 | 51 | 1–1000 | 16.8円 | 856 |
| フルカラープリント | 382 | 3% → 12 | 370 | 1–1000 | 13.9円 | 5,143 |
| **合計** | | | | | | **9,937** |

フルカラー総出力435 = コピー53 ＋ プリント382。明細では
「フルカラー総出力①」「フルカラープリント②」「フルカラーコピー（①−②）」と表記される。

## 控除（ミスプリント控除）は段が無い明細にもある

段（逓減単価）が無くても、**印刷枚数そのものが一律で差し引かれる**明細が多い。
リコー・キヤノンでよくある「ミスプリント1%控除」「2%控除」がこれ。
明細に**「控除」という文言があったら必ず拾う**。見落とすと現状経費を過大に出してしまう。

計算はカウントに率を掛けて**切り上げ**、その枚数を引いてから単価を掛ける。
逓減単価のときと同じ扱いで、段が1つ（一律単価）なだけ。

**いちばん大事なのは、控除は現行契約にしか付いていないという点。**
当社が提案する複合機には控除が無いので、提案側は**実際の印刷枚数そのまま**で計算する。
提案側にも控除を掛けてしまうと、提案が実際より安く見え、導入後に必ず揉める。

例：モノクロ1,000枚／カラー1,000枚、現行 モノクロ1円・カラー10円（控除2%）、
提案 モノクロ0.5円・カラー5.0円。

| | 枚数 | 単価 | 金額 |
| --- | ---: | ---: | ---: |
| 現行 モノクロ | 1,000 − 20 = **980** | 1円 | 980 |
| 現行 カラー | 1,000 − 20 = **980** | 10円 | 9,800 |
| **現行 合計** | | | **10,780** |
| 提案 モノクロ | **1,000**（控除なし） | 0.5円 | 500 |
| 提案 カラー | **1,000**（控除なし） | 5.0円 | 5,000 |
| **提案 合計** | | | **5,500** |

比較表には控除の枚数と率を明記し、「提案側には控除がないため実枚数で計算している」旨を
必ず欄外に書く。あとから「前は控除があった」と言われないための備えでもある。

## 実効単価（提案と比べるための数字）

提案するカウンター単価は一律なので、そのままでは段階単価と比べられない。
**実効単価 = その区分の請求額 ÷ 控除前のカウント** を出して比較する。
控除のぶん、名目の単価より必ず安くなる。ここを名目単価で比べると、
お客様に「話が違う」と言われるので、実効単価で比べる。

上の例では次のようになる。

- モノクロ：3,938 ÷ 1,389 = **2.84円**（名目は3.0円）
- フルカラーコピー：856 ÷ 53 = **16.15円**（名目は16.8円）
- フルカラープリント：5,143 ÷ 382 = **13.46円**（名目は13.9円）

## 比較表への載せ方

**行を増やして、現状の内訳をそのまま見せる。** 一律単価の案件と同じ3行
（モノクロ／2色／フルカラー）に押し込めると、段階や控除が消えて
「なぜこの金額なのか」が説明できなくなる。

現状側は区分ごとに1行ずつ立て、段が複数ある区分は段ごとに行を足す。

```
                        現状利用状況              導入提案予測
モノクロ 1-1000枚      3.0円 × 1,000 = 3,000     0.7円 × 4,350 = 3,045
モノクロ 1001-2000枚   2.6円 × 361   =   938
モノクロ 控除(2%)      -28枚
フルカラーコピー       16.8円 × 51   =   856     7.0円 × 435 = 3,045
フルカラープリント     13.9円 × 370  = 5,143
フルカラー 控除(3%)    -14枚
カウンター請求合計                     9,937                    6,090
```

提案側は一律単価なので1行で済む。行数が左右で合わなくてよい。
合計行（カウンター請求合計）だけは必ず左右で並べる。ここが比較の要になる。

## 提案時に押さえること

- **枚数が増えるほど現状が有利になる構造**。提案単価が現状の実効単価を下回っていても、
  お客様の枚数が伸びると差が縮む。月間枚数が大きく変動する客先では、
  現状の直近数ヶ月の平均で比較する（1ヶ月だけで判断しない）。
- **トナー込み契約かどうかを明細で確認する**。「トナー込み契約です」と書いてあれば
  トナー代は別途発生しないので、提案側もトナー込みで比較する。
- 控除（1〜3%）は提案側には無い。**控除は現行側だけに効かせ、提案側は実枚数で計算する。**
  そのうえで、控除の率と枚数を比較表の欄外に必ず書いておく。
- 段階単価は「使うほど安い」ので、お客様は得をしている感覚を持っている。
  価格だけで押すと弱い。保守対応・機能・機械の状態と併せて提案する。

## ツール（複合機見積作成ツール）で扱うとき

- 読み取り側は、区分ごとに **枚数・実効単価・金額** を持たせる。
  段の内訳は明細の行をそのまま保持しておき、比較表で行に展開する。
- 現状のカウンター単価欄には**実効単価**を入れる。名目単価を入れると
  現状経費が実際の請求額より高く出てしまい、削減額を過大に見せることになる。
- 検算（合計＝明細の請求額）が合わない読み取り結果は採用せず、
  画面に「明細の合計と一致しません」と出して手入力を促す。
- 控除は現行機の項目として持たせ、提案の計算には**渡さない**。
  同じ関数に控除率を渡してしまう作りにすると、いつか提案側にも掛かる。

## 複合機が複数台ある案件

台数が複数あるときは、A3ヨコ1枚の**複数台比較表**を使う。
設置場所ごとに現行機と提案機を左右に並べ、次の4ブロックを縦に置く。

1. リース料金 詳細内訳（台ごとの月額リース料 → 消費税 → 合計）
2. カウンター料金 詳細内訳比較（台ごとの区分・チャージ枚数・単価・印刷枚数・金額 → 請求金額）
3. 合計（単月／年間／6年間）
4. トータル削減料金（単月／年間／7年間）と削減率、年間売上高に換算した削減効果

台ごとの請求金額は
**( max(カウンター区分の合計, 最低基本料金) ＋ 月額保守料金 ) × 消費税**。
最低基本料金は下回った月に置き換わる**下限**であって加算ではない。
月額保守料金（理想科学のインクジェット等）はカウンターとは別建てで**加算**する。

入替せず据え置く台も1行として並べる。据え置く台は控除もそのまま残る。
