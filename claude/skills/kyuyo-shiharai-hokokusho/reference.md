# 給与支払報告書 — 各欄と計算の根拠

## 提出のあらまし

| | |
| --- | --- |
| 誰が | 給与を支払った事業主（法人・個人問わず） |
| 誰について | 前年中に給与を支払った全員。パート・アルバイト・中途退職者も含む |
| どこへ | その年の **1 月 1 日現在**に受給者が住んでいた市区町村 |
| いつまで | **1 月 31 日**（休日なら翌開庁日） |
| 何を | 個人別明細書（1 人 1 枚）＋ 総括表（市区町村ごとに 1 枚） |

税務署に出す「源泉徴収票」と中身はほぼ同じだが、**提出先も提出範囲も別**。
税務署への源泉徴収票は年収 500 万円超の人など提出範囲が限られるのに対し、
市区町村への給与支払報告書は原則として全員ぶん出す。

前々年に税務署へ提出した源泉徴収票が 100 枚以上なら、eLTAX または光ディスクでの
提出が義務になる。

## 特別徴収と普通徴収

原則は **全員が特別徴収**（事業主が毎月の給与から住民税を天引きして納付）。
普通徴収にできるのは市区町村が認める限られた場合だけで、たとえば

- 退職者・退職予定者
- 給与が少なく住民税を天引きしきれない人
- 他の事業所で特別徴収されている人
- 乙欄適用者
- 事業所の総受給者が 2 人以下（市区町村により扱いが違う）

普通徴収にする場合、多くの市区町村で「普通徴収切替理由書」の添付を求められる。
入力ブックの `徴収区分` はこの区分をそのまま書く。総括表の報告人員はここから自動集計する。

## 給与所得控除後の金額

所得税法別表第五の考え方で計算している（`salary_income()`）。
**令和 7 年分（2025 年分）から給与所得控除の最低保障額が 55 万円 → 65 万円に
引き上げられた**ので、対象年で表を切り替えている。

### 令和 7 年分以降

| 支払金額 A | 給与所得控除後の金額 |
| --- | --- |
| 1,900,000 未満 | A − 650,000（下限 0） |
| 1,900,000 〜 3,599,999 | B × 2.8 − 80,000 |
| 3,600,000 〜 6,599,999 | B × 3.2 − 440,000 |
| 6,600,000 〜 8,499,999 | A × 0.9 − 1,100,000 |
| 8,500,000 以上 | A − 1,950,000 |

B = A ÷ 4 の 1,000 円未満切捨て。

### 令和 2 年分 〜 令和 6 年分

最低保障額が 55 万円。1,619,000 〜 1,627,999 円のところに 4 段の固定額区分がある。

| 支払金額 A | 給与所得控除後の金額 |
| --- | --- |
| 550,999 以下 | 0 |
| 551,000 〜 1,618,999 | A − 550,000 |
| 1,619,000 〜 1,619,999 | 1,069,000 |
| 1,620,000 〜 1,621,999 | 1,070,000 |
| 1,622,000 〜 1,623,999 | 1,072,000 |
| 1,624,000 〜 1,627,999 | 1,074,000 |
| 1,628,000 〜 1,799,999 | B × 2.4 + 100,000 |
| 1,800,000 〜 3,599,999 | B × 2.8 − 80,000 |
| 3,600,000 〜 6,599,999 | B × 3.2 − 440,000 |
| 6,600,000 〜 8,499,999 | A × 0.9 − 1,100,000 |
| 8,500,000 以上 | A − 1,950,000 |

所得金額調整控除（年収 850 万円超で 23 歳未満の扶養親族がいる等）が
ある人は、この金額からさらに差し引く。自動計算はしないので
`所得金額調整控除額` 欄に入れたうえで `給与所得控除後の金額` を直接指定する。

## 所得控除の額の合計額

空欄のときだけ、入力された控除額を足して参考値を出す（`deduction_total()`）。

足しているもの:

- 社会保険料等の金額
- 生命保険料の控除額 / 地震保険料の控除額
- 配偶者（特別）控除の額 / 特定親族特別控除の額
- **基礎控除の額（入力された値のみ）** — 年と本人の合計所得で変わるので自動では入れない
- 扶養控除 — 特定 63 万 / 同居老親等 58 万 / その他の老人 48 万 / 一般 38 万
- 障害者控除（扶養親族等） — 同居特別 75 万 / 特別 40 万 / その他 27 万
- 本人に係る控除 — 特別障害者 40 万、一般障害者 27 万、寡婦 27 万、ひとり親 35 万、勤労学生 27 万

**基礎控除は必ず自分で入れる。** 令和 7 年・8 年分は本人の合計所得金額に応じて
58 万円に上乗せがある時限措置が入っており、額が一律ではない。
年末調整の結果に出ている額をそのまま `基礎控除の額` 欄に書く。

## 令和 7 年分からの主な変更

年末調整・様式まわりが同時に動いているので、実際の数字は必ず年末調整の結果で確認する。

- 給与所得控除の最低保障額 55 万円 → 65 万円
- 基礎控除の引き上げ（58 万円、令和 7・8 年分は所得に応じた上乗せの特例あり）
- 扶養親族等の合計所得金額要件 48 万円 → 58 万円（給与収入なら 103 万円 → 123 万円）
- **特定親族特別控除**の新設（19 歳以上 23 歳未満、合計所得 58 万円超 123 万円以下の親族）。
  これに伴い様式に「特定親族特別控除の額」欄が増えた

## 入力欄と様式の対応

入力ブックの列名は、様式の欄名にそろえてある。読み替えが要るのは次だけ。

| 入力ブックの列 | 様式の欄 |
| --- | --- |
| `扶養親族_特定` `扶養親族_老人` `扶養親族_その他` | 控除対象扶養親族の数（配偶者を除く） |
| `扶養親族_老人のうち同居老親等` | 老人欄の「内」 |
| `障害者_特別（本人を除く）` ほか | 障害者の数（本人を除く） |
| `本人が障害者` | 中段の区分欄（`特別` または `○`） |
| `乙欄` | 区分欄の乙欄。`○` を入れる |

区分欄（未成年者・外国人・死亡退職・災害者・乙欄・寡婦・ひとり親・勤労学生）は
該当するとき `○` を入れる。
