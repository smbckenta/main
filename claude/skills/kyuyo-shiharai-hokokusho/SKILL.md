# 給与支払報告書を作る

## この書類は何か

前年 1〜12 月に支払った給与を、従業員が **その年の 1 月 1 日に住んでいた市区町村** へ報告するもの。
市区町村はこれを見て住民税額を決める。提出期限は **翌年 1 月 31 日**。

2 種類あり、セットで提出する。

- **個人別明細書** — 従業員 1 人につき 1 枚。中身は源泉徴収票とほぼ同じ
- **総括表** — 提出先の市区町村ごとに 1 枚。表紙にあたる

## 進め方

### 1. 入力用ブックを作る

```bash
python3 scripts/kyuyo_report.py init "入力.xlsx" --year 2025
```

`支払者`（会社の情報。毎年ほぼ同じ）と `受給者`（1 行 = 1 人）の 2 シートができる。
2 年目以降は前年の入力ブックをコピーして、対象年と金額だけ直せばよい。

### 2. 入力する

金額は **年末調整の結果をそのまま転記する**。給与明細を足し上げて自分で計算しない
（賞与・通勤手当の非課税分・年調過不足でずれる）。

必須は `氏名` / `提出先市区町村` / `徴収区分` / `支払金額` / `源泉徴収税額` の 5 つ。
残りは該当する人だけ埋める。

- `提出先市区町村` — **1 月 1 日時点**の住所地。年末に引っ越した人は間違えやすい
- `徴収区分` — `特別徴収` / `普通徴収（退職者）` / `普通徴収（退職者を除く）` のいずれか。
  原則は全員 `特別徴収`。普通徴収にできるのは退職者や乙欄該当者など限られた場合だけで、
  多くの市区町村では別途「普通徴収切替理由書」が要る
- `給与所得控除後の金額` / `所得控除の額の合計額` — 空欄なら参考値を自動計算する
  （計算根拠は reference.md）。年末調整の数字があるならそちらを直接入れる

### 3. 生成する

```bash
python3 scripts/kyuyo_report.py build "入力.xlsx" --out "給与支払報告書_2025年分.xlsx"
```

`個人別明細書`（人数ぶん、改ページ入り）と `総括表`（市区町村ごと）の 2 シートができる。
自動計算で埋めた欄がある人は実行結果に名前が出るので、必ず年末調整の結果と突き合わせる。

## 保存先

`▲0Claude\給与支払報告書\<年>年分\` に置く。入力ブックと生成物を同じ場所に残しておくと
翌年そのまま使い回せる。個人番号を含むので、共有範囲は広げない。

## 提出前に必ず確認すること

- **実際の提出は eLTAX（地方税ポータル）が原則。** 前々年の源泉徴収票が 100 枚以上なら
  eLTAX か光ディスクでの提出が義務。このスクリプトが作るのは私製様式なので、
  紙で出す場合は提出先市区町村が私製様式を受け付けるか先に確認する
  （多くは受け付けるが、指定番号欄や様式番号を求められることがある）
- 税務署に出す源泉徴収票、本人に渡す源泉徴収票とは提出先も期限も別物
- 金額・区分の最終判断は顧問税理士に確認する。このスクリプトの自動計算は下書き用
