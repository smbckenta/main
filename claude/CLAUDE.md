## 作業フォルダとファイルの保存先

作業のルートは、Google ドライブの共有ドライブ内にある **`▲0Claude`** フォルダです。

- Windows でのパスは環境変数 `CLAUDE_WORKSPACE` に入っています
  （通常 `G:\共有ドライブ\★Kevin\▲0Claude`）。
- パスに `★` `▲` が含まれるため、コマンドで指定するときは必ず引用符で囲むこと。

保存先のルール:

1. **保存先の指定が特にないファイルは `▲0Claude` 配下に保存する。**
   ホームディレクトリやデスクトップ、カレントディレクトリに勝手に置かない。
2. **既存プロジェクトの成果物は、これまでどおりそのプロジェクトのフォルダに保存する。**
   例: 支払通知書 PDF は `▲0Claude\ev-partner-payment-notice\` 配下のまま。
   既存の保存場所を新しい場所へ移動しない。
3. 新しい案件は `▲0Claude` 直下にその案件用のフォルダを作って、その中で作業する。
4. 一時ファイル・作業用スクリプト・中間生成物は `▲0Claude` に置かず、
   一時ディレクトリを使う（同期対象を汚さないため）。

## Google ドライブ上で作業するときの注意

- `▲0Claude` は 3 台の PC で同期されるため、**同じフォルダを 2 台で同時に編集しない**。
- git リポジトリを置く場合、同期の競合で `.git` が壊れることがある。
  リポジトリを扱う作業は 1 台に固定するか、ドライブ外のローカルに clone する。
- 大量の小さいファイル（`node_modules` など）は同期が重くなるので、
  `.gitignore` 相当のものは Drive 側でも同期対象から外すか、ドライブ外に置く。

## 作業の進め方

- 変更前に、まず既存コードの書き方（命名・コメント量・イディオム）に合わせる。
- テストがあるリポジトリでは、変更後に該当範囲のテストを実行して結果を報告する。
