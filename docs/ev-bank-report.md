# EV案件管理表を銀行提出用 Excel にする

Google スプレッドシート **「【EVPT】エレベーター特約店管理表」** の
**「【成約済】EV案件 管理表」** シートを、銀行にそのまま出せる
**A3・5ページ**の Excel に変換する定型作業です。

> 元のスプレッドシートは読み取るだけで、**一切編集しません。**

---

## 自動保存の設定（最初に 1 回だけ）

保存先の

```
G:\共有ドライブ\★Kevin\☆重要\f\EV関連
```

は **Google ドライブ（共有ドライブ「★Kevin」）のフォルダ**です。
ここへ保存すれば、そのままクラウドにも他の PC にも同期されます。

次の 1 行を PowerShell で 1 回だけ実行すると、以後は**自動で作成・保存**されます。

```powershell
.\scripts\Install-EvBankReportTask.ps1
```

登録されるタスクスケジューラの内容:

| | |
|---|---|
| 実行タイミング | 毎月 1 日 09:00 ／ PC にログオンしたとき |
| PC が消えていたら | 次に起動したときに取りこぼしぶんを実行 |
| 変換元 | `EV関連` フォルダ →ダウンロードフォルダ の順で、最新の `【EVPT】〜.xlsx` を自動で探す（末尾 6 桁の提出用ファイルは除外） |
| 保存先 | `G:\共有ドライブ\★Kevin\☆重要\f\EV関連` |
| ファイル名 | `【EVPT】エレベーター特約店管理表YYMMDD.xlsx` |
| 二重作成 | 同じ日付のファイルが既にあり、変換元より新しければ何もしない |
| ログ | `%LOCALAPPDATA%\EvBankReport\run.log` |
| 管理者権限 | 不要 |

日付や時刻を変えたいとき、やめたいとき:

```powershell
.\scripts\Install-EvBankReportTask.ps1 -DayOfMonth 5 -At 08:30
.\scripts\Install-EvBankReportTask.ps1 -Uninstall
```

> **唯一の手作業**は、スプレッドシートを
> `ファイル` → `ダウンロード` → `Microsoft Excel (.xlsx)` で保存することだけです。
> ダウンロードフォルダに置いても、`EV関連` フォルダに直接置いても構いません。
> あとはタスクが拾って変換します。

---

## 手で実行する

```powershell
.\scripts\Make-EvBankReport.ps1
```

引数なしで、最新の `【EVPT】〜.xlsx` を自動で拾って変換し、保存先フォルダを開きます。

```powershell
# ファイルを指定する
.\scripts\Make-EvBankReport.ps1 -Source "$HOME\Downloads\【EVPT】エレベーター特約店管理表.xlsx"

# Python を直接叩く
python scripts\make_ev_bank_report.py "$HOME\Downloads\【EVPT】エレベーター特約店管理表.xlsx"
```

実行するとこう表示されます。

```
作成しました: G:\共有ドライブ\★Kevin\☆重要\f\EV関連\【EVPT】エレベーター特約店管理表260902.xlsx
  件数        : 262 件（267 行目が空欄のため、それ以降は対象外）
  用紙        : A3 横 / 横 1 ページ幅
  ページ数    : 5 ページ（目標 5 ページ以内）
  文字        : 9.5pt × 縮小率 94% → 紙の上で 約 8.9pt
```

**オプション**

| やりたいこと | `Make-EvBankReport.ps1` | `make_ev_bank_report.py` |
|---|---|---|
| 変換元を指定 | `-Source "<パス>"` | 第1引数 |
| 保存先を変える | `-OutDir "D:\提出用"` | `-o "D:\提出用"` |
| 作成日を指定 | `-Date 260511` | `--date 260511` |
| ページ数を変える | `-Pages 4` | `--pages 4` |
| 同じ日付でも作り直す | `-Force` | （常に上書き） |
| 折り返しをやめる | — | `--lines 1` |

## 印刷する

できた Excel を開いて `Ctrl+P`。用紙 **A3・横・横1ページ幅**は設定済みなので、
プリンタで A3 を選ぶだけです。

---

## 印刷する行の決め方

| ルール | 内容 |
|---|---|
| **空欄の行で打ち切り** | 見出しの下へ走査して、**出力する18列がすべて空の行**に当たったら、その行以降は印刷対象から外す（現データでは 267 行目） |
| **「凛」を除外** | `開始月` が `凛` の行は出力しない |
| 印刷範囲 | 明細の最終行までを `print_area` に設定するので、余計な空白ページは出ない |

現在のデータでは **262 件**（打ち切りで 12 件、`凛` で 2 件が対象外）。

---

## ページ数と文字の大きさ

`--pages` で指定したページ数に収まる範囲で、**列幅と文字サイズをスクリプトが自動で決めます**。
列幅は必ず A3 の紙幅いっぱい（縮小率 100%）になるようにし、そこへ収まる文字サイズを逆算します。
列を細くするほど文字は大きくなりますが、折り返しが増えてページも増える、という関係です。

| `--pages` | 紙の上の文字 | 用途 |
|---|---|---|
| 4 | 約 7.5pt | とにかく枚数優先 |
| **5（既定）** | **約 8.9pt** | 標準 |
| 6 | 約 10.4pt | |
| 8 | 約 12.5pt | |
| 10 | 約 15.0pt | ページ数を気にせず最大限に大きく |

（現在の 262 件での実測値。件数が増えれば同じページ数でも文字は小さくなります。
3 ページは文字サイズの下限に達するため収まりません。）

> **参考：頂いた元の手作業版**は A3 縦・全列・横1ページ幅で、
> 縮小率 36%＝紙の上で **約5pt** でした。同じ枚数感で **約9pt**、1.8 倍です。

長い文字列は、列幅の 1.4 倍までの超過なら **1行のまま自動縮小**、
それを超える長文だけ **2行に折り返し**ます（現データで 21 行）。
軽い超過で行が倍の高さになり、ページが増えるのを防ぐためです。

## 何が変わるのか

### 消す列（銀行提出では不要な社内管理用）

`PT①` / 2つ目の `担当` / `既存契約` / `仕様` / `ベンダー` / `既存料金` / `結果番号` /
Z列以降の集計ダッシュボード / 1〜3行目の社内メモ（「PTI支払管理のコードDB転記完了」など）

### 残す列（18列）

| | | | |
|---|---|---|---|
| 成約Code | 担当 | 顧客名 | 物件名 |
| 開始月 | 弊社入金月 | 提案内容 | 基数 |
| 契約形態 | 点検頻度 | OP | 仕切 |
| 見積料金 | ❶EVPT売上 | ❷PTI | ❸EVPT NP |
| 結果 | 備考 | | |

### 見やすさの工夫

| 工夫 | ねらい |
|---|---|
| **本文を太字** | 細字は紙の上で線が細って読みにくいため、明細も見出しもすべて太字 |
| **担当ごとに色分け** | 誰の案件かが一目で分かる（小坂＝青／山内＝緑／河内山＝橙／ライクタイガー＝紫／啓就＝黄／諸富＝水／上野＝桃）。表に無い担当にも自動で色を割り当てます |
| **`結果` は 7 種すべて別の色** | 保守成約＝緑／リニュ成約＝青／新設成約＝紫／進捗中＝橙／保留＝黄／失注＝灰／解約＝赤。地色と文字色をそろえたチップ風 |
| **見出しを列グループごとに色分け** | `案件`＝紺／`時期`＝青／`契約`＝緑青／`金額`＝緑／`結果`＝グレー。18列でも今どのブロックを見ているか分かる |
| **グループの境目に太い縦罫線** | 金額ブロックなどのまとまりが視覚的に切れる |
| **開始年が変わる行に区切り線** | 年ごとのまとまりが分かる（データは開始月順） |
| **1行おきの薄い縞** | 横方向に目で追いやすい |
| **失注・解約の行は文字を薄く** | 生きている契約が浮き上がる |
| **`¥0` を薄いグレー** | ゼロが並んでも数字が読み取りやすい |

### そのほか

- 数式は**計算結果の値**に確定（`#VALUE!` `#N/A` などのエラー表示は空欄に）
- 表題は 1 ページ目だけ、**見出し行は全ページの先頭に繰り返し印刷**
- 見出し行と `物件名` までの列を画面固定（スクロールしても見出しが残る）
- フッターにページ番号（`1 / 5` の形式）

## 仕様メモ

### 列の探し方

列の位置ではなく**見出し名**で探すので、元シートで列を追加・移動しても
そのまま動きます。見出し名自体を変えたときだけ
`scripts/make_ev_bank_report.py` の `COLUMNS` を直してください。

### 調整できる箇所

`scripts/make_ev_bank_report.py` の冒頭にまとめてあります。

| 変えたいこと | 定数 |
|---|---|
| 既定のページ数 | `TARGET_PAGES` |
| フォント | `FONT_NAME` |
| 列幅の探索範囲 | `WIDTH_FACTOR_MIN` / `WIDTH_FACTOR_MAX` |
| 文字サイズの上下限 | `FONT_MIN` / `FONT_MAX` |
| 折り返しの判定 | `WRAP_THRESHOLD` / `MAX_LINES` |
| A3 の向き | `ORIENTATION` |
| 列の取捨と列幅の配分 | `COLUMNS`（幅は「半角何文字ぶん」で指定） |
| 除外する `開始月` の値 | `EXCLUDE_START_MONTH` |
| 本文の太字 | `BODY_BOLD` |
| 担当ごとの色 | `OWNER_FILLS` / `OWNER_PALETTE` |
| 列グループと見出し色 | `COLUMN_GROUPS` |
| `結果` の色分け | `RESULT_STYLES` |
| 保存先 | `DEFAULT_OUT_DIR` |
| ファイル名の頭 | `FILE_STEM` |

### 必要なもの

Python 3 と `openpyxl` だけです。

```powershell
pip install openpyxl
```
