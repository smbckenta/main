# EV案件管理表を銀行提出用 Excel にする

Google スプレッドシート **「【EVPT】エレベーター特約店管理表」** の
**「【成約済】EV案件 管理表」** シートを、銀行にそのまま出せる
**A3・大きな文字**の Excel に変換する定型作業です。

> 元のスプレッドシートは読み取るだけで、**一切編集しません。**

---

## 毎回の流れ（3ステップ）

### 1. スプレッドシートを .xlsx でダウンロード

スプレッドシートを開いて
`ファイル` → `ダウンロード` → `Microsoft Excel (.xlsx)`

### 2. 変換スクリプトを実行

```powershell
python scripts\make_ev_bank_report.py "$HOME\Downloads\【EVPT】エレベーター特約店管理表.xlsx"
```

保存先とファイル名は自動で決まります。

```
G:\共有ドライブ\★Kevin\☆重要\f\EV関連\【EVPT】エレベーター特約店管理表260902.xlsx
                                                             └─ 作成日 YYMMDD
```

実行するとこう表示されます。

```
作成しました: G:\共有ドライブ\★Kevin\☆重要\f\EV関連\【EVPT】エレベーター特約店管理表260902.xlsx
  件数        : 274 件
  用紙        : A3 横 / 横 1 ページ幅
  印刷縮小率  : 約 72%（本文 16pt → 実寸 約 11.5pt）
  想定ページ数: 約 14 ページ
```

**オプション**

| やりたいこと | 書き方 |
|---|---|
| 保存先を変える | `-o "D:\提出用"` |
| 作成日を指定する | `--date 260511`（YYMMDD の 6 桁） |

### 3. 印刷する

できた Excel を開いて `Ctrl+P`。用紙 **A3・横・横1ページ幅**は設定済みなので、
プリンタで A3 を選ぶだけです。

---

## 何が変わるのか

### 消す列（銀行提出では不要な社内管理用）

`PT①` / 2つ目の `担当` / `既存契約` / `仕様` / `ベンダー` / `既存料金` / `結果番号` /
Z列以降の集計ダッシュボード / 1〜3行目の社内メモ（「PTI支払管理のコードDB転記完了」など）

### 残す列（18列）

| | | | |
|---|---|---|---|
| 成約Code | 担当 | 顧客名 | 物件名 |
| 開始月 | 弊社入金月 | 提案内容 | 基数 |
| 契約形態 | 点検頻度 | OP | 仕切 |
| 見積料金 | ❶EVPT売上 | ❷PTI | ❸EVPT NP |
| 結果 | 備考 | | |

### 大きくする

| | 変換前（現在の手作業版） | 変換後 |
|---|---|---|
| 用紙 | A3 縦 | **A3 横** |
| 文字 | 14pt | **16pt** |
| 行の高さ | 30pt 固定 | **34pt 以上（折り返しに応じて自動）** |
| 印刷の縮小率 | 約 36% | **約 72%** |
| 紙の上の実寸 | 約 5pt | **約 11.5pt（2倍以上）** |

横1ページ幅に収める点は同じですが、不要な列を落として列幅を整えたぶん
縮小率が半分で済むようになり、印刷したときの文字が 2 倍以上大きくなります。

### そのほか

- 数式は**計算結果の値**に確定（`#VALUE!` `#N/A` などのエラー表示は空欄に）
- 表題と見出しを**全ページの先頭に繰り返し印刷**
- `結果` を色分け（成約＝緑／進捗中・保留＝黄／失注＝灰／解約＝赤）
- 見出し行と `物件名` までの列を画面固定（スクロールしても見出しが残る）
- フッターにページ番号（`1 / 14` の形式）

## 仕様メモ

### 1件として数える行

`成約Code` は未採番の行があるため使いません。**`結果` 列が入っている行**を
1件として扱います（現在 274 件）。

### 列の探し方

列の位置ではなく**見出し名**で探すので、元シートで列を追加・移動しても
そのまま動きます。見出し名自体を変えたときだけ
`scripts/make_ev_bank_report.py` の `COLUMNS` を直してください。

### 調整できる箇所

`scripts/make_ev_bank_report.py` の冒頭にまとめてあります。

| 変えたいこと | 定数 |
|---|---|
| 文字の大きさ | `FONT_SIZE` |
| フォント | `FONT_NAME` |
| A3 の向き | `ORIENTATION` |
| 列幅・列の取捨 | `COLUMNS` |
| 保存先 | `DEFAULT_OUT_DIR` |
| ファイル名の頭 | `FILE_STEM` |

> **文字をもっと大きくしたいときは** `FONT_SIZE` を上げてください。
> 列幅はそのままなので印刷実寸も比例して大きくなりますが、
> 折り返しが増えてページ数も増えます（16pt・274件で A3 約 14 ページ）。

### 必要なもの

Python 3 と `openpyxl` だけです。

```powershell
pip install openpyxl
```
