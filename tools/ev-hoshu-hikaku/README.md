# EV保守 価格比較表 作成ツール

昇降機（エレベーター・エスカレーター）の **定期検査報告書** と **保守契約書** を
Claude に読ませて、**EVパートナーズ株式会社名義の「EV保守 価格比較表」** を作るツールです。

出力は既存のひな形 Excel をそのまま使うので、書式・ロゴ・印刷設定は手作業のものと同じになります。
明細は8行固定ではなく、**案件の件数に合わせて自動で増減**します。

作りは複合機見積ツールに合わせています。**アプリ本体はローカル、データは Google ドライブ**です。

```
アプリ（この tools/ev-hoshu-hikaku/ 一式）
├── index.html          ← ブラウザで開く
├── app.js
├── lib/                zip / xlsx 差し込み / Claude / 保存先
├── template/           ひな形 Excel
└── data-template/      data フォルダの雛形

データ（▲0Claude 配下に置く。3台で同期される）
▲0Claude\ev-hoshu-hikaku\data\
├── settings.json       自社情報と既定値
├── api-key.txt         Claude API キー（1行だけ）
├── template.xlsx       ひな形（初回に取り込まれる）
├── cases\<id>.json     案件
├── uploads\<id>\       読み取らせた元の書類
└── exports\            書き出した Excel の控え
```

---

## 起動

**`start.cmd` をダブルクリック**してください。ローカルサーバーが立ち上がり、
既定のブラウザで `http://127.0.0.1:<ポート>/` が開きます。閉じるときはコンソールで `Ctrl+C`。

Node.js があれば追加のインストールは要りません（Claude Code が動いていれば入っています）。
mac / Linux は `./start.sh`、ポートを決め打ちしたいときは `node serve.js 8080` です。

`index.html` を直接ダブルクリックしても動きますが、`file://` だとブラウザの設定によって
フォルダ選択（File System Access API）が使えないことがあるので `start.cmd` を勧めます。

> **Chrome か Edge で開いてください。** Firefox / Safari はフォルダ保存に対応していません。

## 準備（初回だけ）

1. `▲0Claude\ev-hoshu-hikaku\data\` を作る
2. `data-template\settings.json` を `data\settings.json` にコピーし、担当者名を入れる
3. `data\api-key.txt` を作り、Claude の API キーを1行だけ書く
4. `start.cmd` で開き、「データフォルダを接続」→ 手順1で作った `data` フォルダを選ぶ

ひな形は初回の Excel 書き出し時に `template\ev-hikaku-template.xlsx` から
`data\template.xlsx` へ自動で取り込まれます（`file://` で開いたときだけ手で選びます）。

> API キーは `data` フォルダに置くので、**ドライブの共有範囲＝キーの共有範囲**になります。
> 共有ドライブの権限を確認してから置いてください。

## デモ版

`python3 scripts/build-demo.py` で `demo/ev-hikaku-demo.html` を作ると、
本体をそのまま埋め込んだ1ファイルのデモができます。ブラウザで開くだけで動き、
設定もフォルダ選択も要りません（claude.ai の Artifact として公開するのもこれです）。

本体との違いは3点だけで、差し替えているのは `demo/` の3ファイルです。

| 差し替え | 本体 | デモ |
| --- | --- | --- |
| `demo/store-demo.js` | Google ドライブの data フォルダ | ブラウザの localStorage |
| `demo/ai-demo.js` | Claude API に PDF を送る | 用意した読み取り結果を再生 |
| `demo/download-demo.js` | ファイルをダウンロード | 生成のみ（Artifact は .xlsx を保存できない） |

画面と Excel 生成は本体のコードをそのまま使うので、本体を直したら作り直すだけで揃います。

## 使い方

### ① 書類読み取り

定期検査報告書・保守契約書（PDF / 画像）をドラッグして「Claude で読み取る」。

読み取った内容は **確度・根拠・警告つき** で表示されます。
根拠は原文の引用なので、金額や契約種別はここで突き合わせてください。
問題なければ「明細に取り込む」で②③へ渡ります。

- 定期検査報告書からは号機ごとの情報が **②昇降機台帳** に、
  保守契約書からは料金・契約種別が **③明細** に入ります
- 同じ設置場所の書類は1行にまとめます（号機は設置場所＋号機番号、無ければ製造番号で突き合わせます）
- **入力済みの欄は上書きしません。** 手で直した内容は読み取りを繰り返しても残ります
- 税込表記を読み取ったときは警告に出ます。税抜に直してください
- 元の書類は `uploads\<案件id>\` に残るので、後から根拠をたどれます

### ② 昇降機台帳

読み取った号機を1枚ずつのカードに整理します。号機番号・用途・メーカー・型式・製造番号、
確認済証／検査済証の交付年月、積載量・定員・定格速度・停止階数、検査者、指摘事項が並びます。

**年月は西暦と和暦の両方で表示します。** 入力はどちらでも構いません
（`2003-04` でも `平成15年4月` でも `H15.4` でも受け付け、`2003-04` に揃えて保存します）。

**更新時期の判定** は各カードの上の帯に出ます。

| 起点 | いつ使うか |
| --- | --- |
| 最終リニューアル年月 | リニューアル履歴があるとき（最も新しいもの） |
| 確認済証交付年月 | リニューアル履歴が無いとき |
| 製造年月 → 設置年月 | 確認済証交付年月が読み取れなかったときの代用 |

起点から **25年** 経過するとアラートになります。カード左の帯が赤くなり、
「25年経過（30年5ヶ月）」のバッジが付き、タブに件数が出ます。
25年まで3年を切った号機は黄色で「あと約◯年で25年」と出ます。

リニューアルを実施したら「＋ リニューアルを追加」で年月と内容を入れてください。
起点がその年月に切り替わり、**そこから25年**で数え直します。
履歴が複数あるときは一番新しいものが「最終」になります。

### ③ 明細

現行と提案を左右に並べた表です。上の「提案側を一括で埋める」で、
提案ベンダー・点検頻度・仕様・契約内容と削減率をまとめて反映できます。
一括反映の内容はそのまま既定値として保存されるので、次の案件から入力が減ります。

提案側の **点検頻度は常に赤字**、**契約内容は現行と変わる行だけ赤字**になります（ひな形と同じ見せ方）。

### ④ 表紙・備考

宛先・タイトル・作成日、右上の作成者4行、累計年数、利益率、備考を設定します。
作成者の既定値は「設定」画面で変えられます。

### ⑤ 比較表

画面がそのまま印刷レイアウトです。

- **印刷 / PDF** … A3横で印刷。PDF 保存もここから
- **Excel を書き出す** … ひな形に流し込んだ `.xlsx` をダウンロードし、`data\exports\` にも控えを残します

## 出力される Excel について

`template/ev-hikaku-template.xlsx` は、実際に使われている比較表そのものです。
ツールはこのファイルを開いて、次の3か所だけを書き換えます。

| 場所 | 中身 |
| --- | --- |
| ヘッダー | 日付・宛先・タイトル・作成者4行 |
| 明細（16行目〜） | 件数に合わせて行ペアを複製／削除し、値を差し込む |
| 合計・削減・備考 | 明細の増減に合わせて行番号と数式をずらす |

セルの書式・罫線・ロゴ・矢印・印刷設定はひな形のまま残ります。
金額は数式（`SUM` や `BY39-Y39`）のまま入るので、Excel 側で数字を直せば合計も追従します。

ひな形を差し替えたいときは `data\template.xlsx` を新しいものに置き換えてください。
ただし **セル位置（明細は16行目から、合計は32行目から）を変えると差し込みが合わなくなります。**

## 制限

- 明細の1行は「1つの設置場所」です。同じ物件に号機が複数あるときは台数でまとめます
- 昇降機台帳（号機ごとの諸元・指摘事項・更新時期）は案件の JSON に持ちますが、
  比較表の Excel には載りません。ひな形に欄がないためです
- 25年という周期は `lib/lifecycle.js` の `RENEWAL_CYCLE_YEARS` にまとめてあります
- ひな形は無圧縮 ZIP で保存してあります（ブラウザ側で展開処理を持たずに済ませるため）。
  Excel で開いて上書き保存すると圧縮されてしまい、ツールから読めなくなります。
  ひな形を編集したら `scripts/pack-template.py` で無圧縮に戻してください
