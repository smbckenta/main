# EV保守 価格比較表 作成ツール

昇降機（エレベーター・エスカレーター）の **定期検査報告書** と **保守契約書** を
Claude に読ませて、**EVパートナーズ株式会社名義の「EV保守 価格比較表」** を作るツールです。

出力は既存のひな形 Excel をそのまま使うので、書式・ロゴ・印刷設定は手作業のものと同じになります。
明細は8行固定ではなく、**案件の件数に合わせて自動で増減**します。

作りは複合機見積ツールに合わせています。**アプリ本体はローカル、データは Google ドライブ**です。

```
アプリ（この tools/ev-hoshu-hikaku/ 一式）
├── index.html          ← ブラウザで開く
├── app.js
├── lib/                zip / xlsx 差し込み / Claude / 保存先
├── template/           ひな形 Excel
└── data-template/      data フォルダの雛形

データ（▲0Claude 配下に置く。3台で同期される）
▲0Claude\ev-hoshu-hikaku\data\
├── settings.json       自社情報と既定値
├── api-key.txt         Claude API キー（1行だけ）
├── template.xlsx       ひな形（初回に取り込まれる）
├── cases\<id>.json     案件
├── uploads\<id>\       読み取らせた元の書類
└── exports\            書き出した Excel の控え
```

---

## 準備（初回だけ）

1. `▲0Claude\ev-hoshu-hikaku\data\` を作る
2. `data-template\settings.json` を `data\settings.json` にコピーし、担当者名を入れる
3. `data\api-key.txt` を作り、Claude の API キーを1行だけ書く
4. `index.html` を **Chrome か Edge** で開く（Firefox / Safari はフォルダ保存に対応していません）
5. 「データフォルダを接続」→ 手順1で作った `data` フォルダを選ぶ
6. 初回の Excel 書き出し時にひな形を聞かれるので `template\ev-hikaku-template.xlsx` を選ぶ
   （選んだものが `data\template.xlsx` に保存され、以後は聞かれません）

> API キーは `data` フォルダに置くので、**ドライブの共有範囲＝キーの共有範囲**になります。
> 共有ドライブの権限を確認してから置いてください。

## 使い方

### ① 書類読み取り

定期検査報告書・保守契約書（PDF / 画像）をドラッグして「Claude で読み取る」。

読み取った内容は **確度・根拠・警告つき** で表示されます。
根拠は原文の引用なので、金額や契約種別はここで突き合わせてください。
問題なければ「明細に取り込む」で②へ渡ります。

- 同じ設置場所の書類は1行にまとめます（検査報告書からメーカー・停止階数、契約書から料金・契約種別）
- **入力済みの欄は上書きしません。** 手で直した内容は読み取りを繰り返しても残ります
- 税込表記を読み取ったときは警告に出ます。税抜に直してください
- 元の書類は `uploads\<案件id>\` に残るので、後から根拠をたどれます

### ② 明細

現行と提案を左右に並べた表です。上の「提案側を一括で埋める」で、
提案ベンダー・点検頻度・仕様・契約内容と削減率をまとめて反映できます。
一括反映の内容はそのまま既定値として保存されるので、次の案件から入力が減ります。

提案側の **点検頻度は常に赤字**、**契約内容は現行と変わる行だけ赤字**になります（ひな形と同じ見せ方）。

### ③ 表紙・備考

宛先・タイトル・作成日、右上の作成者4行、累計年数、利益率、備考を設定します。
作成者の既定値は「設定」画面で変えられます。

### ④ 比較表

画面がそのまま印刷レイアウトです。

- **印刷 / PDF** … A3横で印刷。PDF 保存もここから
- **Excel を書き出す** … ひな形に流し込んだ `.xlsx` をダウンロードし、`data\exports\` にも控えを残します

## 出力される Excel について

`template/ev-hikaku-template.xlsx` は、実際に使われている比較表そのものです。
ツールはこのファイルを開いて、次の3か所だけを書き換えます。

| 場所 | 中身 |
| --- | --- |
| ヘッダー | 日付・宛先・タイトル・作成者4行 |
| 明細（16行目〜） | 件数に合わせて行ペアを複製／削除し、値を差し込む |
| 合計・削減・備考 | 明細の増減に合わせて行番号と数式をずらす |

セルの書式・罫線・ロゴ・矢印・印刷設定はひな形のまま残ります。
金額は数式（`SUM` や `BY39-Y39`）のまま入るので、Excel 側で数字を直せば合計も追従します。

ひな形を差し替えたいときは `data\template.xlsx` を新しいものに置き換えてください。
ただし **セル位置（明細は16行目から、合計は32行目から）を変えると差し込みが合わなくなります。**

---

## 制限

- 明細の1行は「1つの設置場所」です。同じ物件に号機が複数あるときは台数でまとめます
- 号機ごとの指摘事項は読み取って画面に表示しますが、比較表には載りません（比較表のひな形に欄がないため）
- ひな形は無圧縮 ZIP で保存してあります（ブラウザ側で展開処理を持たずに済ませるため）。
  Excel で開いて上書き保存すると圧縮されてしまい、ツールから読めなくなります。
  ひな形を編集したら `scripts/pack-template.py` で無圧縮に戻してください
