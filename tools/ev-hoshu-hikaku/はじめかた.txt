EV保守 価格比較表 作成ツール — はじめかた
=========================================

1. start.cmd をダブルクリックする
   Chrome か Edge でツールが開きます。
   （黒いコンソールが出たままになりますが、使っている間は閉じないでください。
     終わるときはコンソールで Ctrl+C、またはウィンドウを閉じます）

2. 「データフォルダを接続」を押して、保存先のフォルダを選ぶ
   おすすめは Google ドライブの中に作ったこのフォルダです。
     G:\共有ドライブ\★Kevin\▲0Claude\ev-hoshu-hikaku\data
   先にエクスプローラーで空のフォルダを作っておいてください。
   ここに置くと 3 台の PC で同じ案件を見られます。

3. 右上の「設定」で、Claude の API キーを貼る
   書類の読み取りに使います。読み取りを使わない（手入力だけ）なら不要です。

これで準備は終わりです。あとは「＋ 新規案件」から。

使う流れ
--------
  ① 書類読み取り … 定期検査報告書・保守契約書の PDF をドラッグして読み取る
  ② 昇降機台帳  … 号機ごとの諸元と、確認済証交付年月からの経過年数・25年アラート
  ③ 明細        … 現行と提案を左右に並べて金額を詰める
  ④ 表紙・備考  … 宛先、作成者、備考
  ⑤ 比較表      … 画面で確認して、印刷 / PDF か Excel 書き出し

注意
----
  ・Chrome か Edge で開いてください。Firefox / Safari はフォルダ保存に対応していません。
  ・API キーは選んだデータフォルダの中（api-key.txt）に保存されます。
    Google ドライブに置く場合、そのフォルダの共有範囲＝キーの共有範囲になります。
  ・Node.js が必要です。Claude Code が動いている PC なら入っています。

詳しいことは README.md に書いてあります。
