# 複合機 見積・比較表作成ツール

お客様からお預かりした **リース契約書** と **印刷明細書（カウンター明細）** を読み込み、
既存の Excel 帳票と同じ体裁の **御見積書** と **比較表** を、複数メーカー分まとめて
**PDF / Excel** で出力する Web アプリです。

```
資料アップロード → 自動読取 → 提案の自動組み立て → 内容の確認・調整 → PDF/Excel 出力
```

---

## できること

| 要望 | 実装 |
| --- | --- |
| カウンター明細・リース契約書を読み込んで自動判断 | PDF / Excel / CSV を解析し、印刷枚数・現行単価・月額リース料・リース期間・満了日を抽出 |
| 複合機のスペックを自動判断 | 機種スペックDB（初期データ31機種）→ 無ければメーカー公式サイトから取得しDBへ保存 |
| 仕切価格に粗利を乗せて本体価格を算出 | 「仕切＋粗利率」「目標月額リース料から逆算」「販売額計を直接入力」の3方式 |
| カウンター単価をエリア・CVで自動判別 | 研修資料の単価表（カラー枚数別／請求額別）＋メーカー別交渉レンジ＋僻地判定 |
| PTF（代理店報酬）の自動計算 | GP・販売額・固定額・カウンター報酬を組み合わせた設定式（設定画面で調整） |
| 既存フォーマットの流用 | 御見積書・比較表とも既存Excelと同じ項目・並び（本体合計／お値引き／販売額計／カウンター料金／リースシミュレーション／比較表／売上換算効果） |
| PDF と Excel の両方で出力 | PDF は帳票ごと、Excel は1ブックにメーカー別シート＋各社比較シート |
| 複数メーカーを同時に出力 | メーカーを複数選択 → 見積書・比較表を一括生成し ZIP でダウンロード |

## 起動方法

```bash
cd apps/mfp-quote-tool
npm install
npx playwright install chromium   # PDF出力に使う Chromium（初回のみ）
npm run dev                       # http://localhost:3100
```

本番用に動かす場合は `npm run build && npm start`。

### 動作要件

- Node.js 20 以上（22 推奨）
- PDF出力のみ Chromium が必要です。未インストールの場合、Excel は出力され、PDFは警告付きでスキップされます。
- 日本語フォントは実行しているPCのフォントを使います（Windows の游ゴシック／メイリオで確認）。

## データの持ち方

外部DBは不要で、すべて `data/` 配下の JSON です。

| ファイル | 内容 | Git |
| --- | --- | --- |
| `data/price-book.json` | 仕切表（定価・仕切率・仕切価格・明細ひな型・メーカー別注記） | コミットする |
| `data/devices.json` | 機種スペックDB。使うたびに育っていく | コミットする |
| `data/settings.json` | 自社情報・料率・単価表・PTF設定 | 除外（PCごとの設定） |
| `data/quotes/*.json` | 案件データ（顧客情報を含む） | 除外 |

> **取扱注意**
> `data/price-book.json` は仕切表（厳秘・弊社限り）の内容です。リポジトリは必ず非公開のまま運用してください。
> 保存先を変えたい場合は環境変数 `MFP_DATA_DIR` で任意のフォルダを指定できます
> （例：Googleドライブ上の共有フォルダ）。

## 計算ロジック（既存Excelとの対応）

### 見積書

```
本体合計   = 見積明細（定価）の合計
販売額計   = ①目標月額リース料 ÷ リース料率   （既存Excelの「12800 / 1.66%」と同じ）
             ②仕切価格 ÷ (1 − 粗利率)
             ③直接入力
お値引き   = 販売額計 − 本体合計          （マイナス表示）
月額リース = 販売額計 × リース料率
```

リース料率の初期値は既存Excelと同じ **5年 1.95% / 6年 1.66% / 7年 1.45%** です。

### カウンター料金

```
カウンター請求 = モノクロ枚数×単価 + フルカラー枚数×単価 + 2色カラー枚数×単価
                 （合計が最低基本料金を下回る場合は最低基本料金）
```

単価の自動判定は研修資料の2つの表を使い分けられます（設定画面で選択）。

- カラー印刷枚数で判定（〜500枚 0.7/7.0 … 10,001枚〜 0.40/4.0）
- 現行カウンター請求額で判定（〜15,000円 0.7/7.0 … 250,000円〜 0.40/4.0）

判定した単価は、仕切表に登録した **メーカーごとの交渉レンジ**（例：京セラ モノクロ0.4〜0.8／カラー4.0〜8.0）に収められます。
エリアを「僻地」にするとレンジ上限側の単価になります。

### 機種の自動選定

月間総印刷枚数 → 研修資料のグレード表（25枚機 3,000枚以下／35枚機 6,000枚以上／40枚機 8,000枚以上／
50枚機 15,000枚以上／60枚機 20,000枚以上／70枚機 30,000枚以上）→ 仕切表から該当グレード以上で最も近い機種。

### 収益

```
GP（粗利益） = 販売額計 − 仕切価格
PTF          = 設定式（初期値：GP × 20%）
NP（純利益） = GP − PTF
```

## 要確認（初期値のまま使うと実態と合わない項目）

| 項目 | 初期値 | 備考 |
| --- | --- | --- |
| **PTF の計算式** | GP × 20% | 既存Excelでは手入力欄だったため式が不明です。設定画面で実際の取り決めに変更してください |
| 2色カラー単価 | フルカラー単価 × 0.3 | 京セラ提案例（7.0円→2.0円）から。メーカーにより2色設定が無い場合があります |
| 最低基本料金 | 900円 | 東芝は1,500円など、メーカー・案件で変わります |
| リコーの仕切価格 | 幅の中央値 | 仕切表では「¥570,000〜¥610,000」のように幅があるため、案件ごとに実額を入力してください |
| 東芝・リコーの明細ひな型 | 既存の「見積用 定価」シートより | 一部で仕切表の定価と明細合計が一致しません（仕切表画面に差異を表示しています） |

## 読み取りの精度について

読み取りは帳票の書式に依存します。以下は自動で拾えます。

- 「前回指針・今回指針・使用枚数・単価・金額」の並び（指針の差＝枚数、枚数×単価＝金額 で検証）
- 「チャージ枚数 1〜1,000 / 1001〜」のような段階単価（枚数を合算し、加重平均単価に変換）
- 機番ごとの複数台明細（機番でブロック分割）
- 和暦（令和6年4月1日 / R6.4.1）と西暦の混在
- 複数月の明細（期間から月数を割り出して月平均に換算）

読み取れない場合は警告を出したうえで手入力できます。
**スキャン画像のみのPDF（OCRなし）は未対応**です。
