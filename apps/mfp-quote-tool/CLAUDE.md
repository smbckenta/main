# 作業のきまり

## 比較表を作ったら、明細の合計と突き合わせてからお出しする

お預かりしたカウンター明細（請求書・検針票）の合計と、作った比較表の
「カウンター請求合計 ②」が合っているか、**お出しする前に自分で確かめる**。
確かめずに「できました」と言わない。数字は思い込みで判断せず、実際に足して合わせる。

上から順に見て、1つでも外れていたら直してからお出しする。

1. **区分ごとの金額** … 明細の各行（モノクロ／フルカラー／2色カラー …）の金額と、
   比較表の各行が1円まで一致するか。控除の行も含めて数える。
2. **合計** … 比較表の「カウンター請求合計 ②」＝明細の小計（税抜）。
3. **期間** … 明細が何ヶ月ぶんか（「2023/12/10〜2024/03/10」なら3ヶ月）を必ず見る。
   この表はぜんぶ「1ヶ月あたり」で並べる。現行側と提案側が同じ月数になっているか
   （左だけ期間ぶん・右だけ月平均、になっていないか）。
   数ヶ月ぶんの明細なら「（◯月-◯月平均印刷枚数）」の注記が出ているか。
4. **控除** … 控除カウントの枚数が明細の数字と同じか。端数の丸め方はメーカーで違う
   （リコーは切り上げ、シャープは切り捨て）ので、率から計算し直して済ませない。

### 過去に出した間違い

同じ形で繰り返しているので、上の4点はこの2件を思い出しながら見る。

- 控除カウントを一律に切り上げていて、シャープの明細と **11円** ずれた
  （6,501枚の1%＝65.01→明細は65枚、こちらは66枚）。
- 3ヶ月ぶんの明細1枚で、月間印刷枚数は3で割っていたのに内訳の枚数は期間ぶんのままにし、
  現行のカウンター料金を3倍に見せた（カウンター削減額 ▲37,290円 ←実際は▲5,700円ほど）。

どちらも画面もPDFも正しく動いたまま、金額だけが間違っていた。
動いたかどうかではなく、明細の数字と合っているかで確かめる。
