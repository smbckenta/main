複合機 見積・比較表作成ツール


■■ 起動できないときは、まずここ ■■

【1】ZIPは必ず「展開」してから使ってください

　　ZIPをダブルクリックすると中身が見えますが、それは「開いているだけ」で
　　展開はされていません。その状態で start.bat を実行しても動きません。

　　　ZIPファイルを右クリック →「すべて展開」→ 出てきたフォルダを開く

　　※ ZIPの中から実行した場合は「ZIPファイルの中から実行しています」と
　　　 画面に出るようにしてあります。


【2】ダウンロードしたZIPは「ブロック」を外してから展開してください

　　インターネットからダウンロードしたファイルは Windows がブロックします。
　　これが原因だと、start.bat をクリックしても画面すら出ません。

　　　ZIPファイルを右クリック →「プロパティ」
　　　→ 下のほうの「セキュリティ: このファイルは…ブロックされています」の
　　　　 右にある「許可する」にチェック → OK
　　　→ そのあとで「すべて展開」

　　展開したあとに「WindowsによってPCが保護されました」と出た場合は、
　　「詳細情報」→「実行」を押してください。


【3】それでも開かないとき

　　start.bat と同じフォルダに start-log.txt ができます。
　　これを担当者にお送りください。原因が分かります。

　　start.bat は PowerShell を使わない作りです。実行ポリシーや
　　セキュリティ設定で PowerShell が動かないPCでも起動できます。


■ 入れ方

　1. 展開してできた「複合機見積作成ツール」フォルダを、
　　 これまでのフォルダに上書きしてください。
　　 （data は Googleドライブ側なので、案件データ・設定は消えません）
　2. start.bat をダブルクリック。
　　 部品が増えた版に入れ替えたときは、起動に数分かかります。

■ Node.js のインストール（PCごとに1回だけ）

　「Node.js が見つかりません」と出たPCでは、Node.js を入れてください。
　PCを買い替えたときや、別のPCで初めて使うときに必要になります。

　　方法1: スタートメニューから「ターミナル」または「コマンドプロンプト」を開き、
　　　　　 次を実行する（PowerShell でなくても構いません）

　　　　　　winget install OpenJS.NodeJS.LTS

　　方法2: https://nodejs.org を開き、LTS版の Windows Installer (.msi) を
　　　　　 ダウンロードして実行する
　　　　　 （社内の制限で winget が使えない場合はこちら）

　どちらの場合も、入れ終わったらPCを再起動してから
　もう一度 start.bat をダブルクリックしてください。


■ できること

　・お預かりしたリース契約書・支払予定表・カウンター明細（PDF・写真）を
　　AIで読み取り、現行機の条件を自動で埋める
　・仕切表から機種を選び、GP（粗利額）から見積金額とリース料を計算
　・御見積書と比較表を PDF・Excel で出力（複数メーカーを一括出力）
　・複合機が複数台ある案件は、A3ヨコ1枚の複数台比較表で出力
　・見積書番号を Googleスプレッドシートの台帳から採番して転記


■ 更新履歴

2026年8月23日

　1. 複合機が複数台ある案件の「A3ヨコ 複数台比較表」

　　案件画面に「複数台の比較（A3ヨコ 複数台比較表）」という欄が増えました。
　　設置場所ごとに現行機と提案機を入力すると、A3ヨコ1枚の比較表になります。

　　　・リース料金 詳細内訳
　　　・カウンター料金 詳細内訳比較
　　　・合計（単月／年間／リース年数ぶん）
　　　・トータル削減料金と削減率、年間売上高に換算した削減効果

　　台ごとの請求金額は
　　　( max(カウンター計, 最低基本料金) ＋ 月額保守料金 ) × 消費税
　　で計算します。最低基本料金は下回った月に置き換わる「下限」、
　　月額保守料金（理想科学など）は「加算」と、区別しています。

　　「チャージ枚数」の帯（1-4000 など）にも対応しています。
　　入替せず据え置く台は「据え置く」ボタンで現行をそのまま写せます。
　　台数が増えると自動で字を小さくし、16台でも1枚に収まります。

　2. カウンター明細の「控除」（ミスプリント1%控除・2%控除）

　　　現行 モノクロ 1,000枚 −20枚 = 980枚 × 1円 = 980円
　　　現行 カラー　 1,000枚 −20枚 = 980枚 × 10円 = 9,800円 → 合計 10,780円
　　　提案 モノクロ 1,000枚（控除なし）× 0.5円 = 500円
　　　提案 カラー　 1,000枚（控除なし）× 5.0円 = 5,000円 → 合計 5,500円

　　控除は現行契約にしか付いていないため、現行側だけ控除後の枚数で計算し、
　　提案側は実際の印刷枚数そのままで計算します。
　　PDFの読み取りでも「控除」を拾い、比較表の欄外に率と枚数を印字します。

　3. 削減シミュレーションをリース年数に合わせる

　　削減額を「単月／年間／リース年数ぶん」の3段にしました。
　　6年リースで提案すれば自動的に6年間、5年リースなら5年間になります。

　4. start.bat を PowerShell 不要の作りに変更

　　PCによっては PowerShell が止められていて、画面すら出ないことが
　　あったため、cmd だけで完結する作りに変えました。
　　Node.js が PATH に入っていないだけの場合は、既定のインストール先
　　（C:\Program Files\nodejs など）を探しにいって、そのまま起動します。
